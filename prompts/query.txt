You are the main agent for a personal LLM Wiki. Your working directory is `examples/llm-wiki/`.

## Task
Answer this question using ONLY the wiki:

QUESTION: <YOUR_QUESTION>

(Replace the line above with your actual question.)

## How to proceed
1. Delegate the query to the `wiki_query` subagent via the `task` tool. Pass it:
   - The exact question
   - A reminder that the working directory is `examples/llm-wiki/` and wiki files live under `wiki/`
   - Instructions to cite every factual claim with a wiki page path
2. When the subagent returns, present its answer to the user cleanly.
3. If the subagent reports that the wiki is missing information to answer the question, explicitly tell the user:
   - What's missing
   - What sources would be worth ingesting to close the gap
4. If the answer itself is valuable and synthesizes multiple pages in a new way, ask the user whether they want to save it back to the wiki (as a new `topics/` page or appended to an existing one). If yes, delegate the write to `wiki_ingest` with a clearly-marked "self-generated synthesis" note in the source metadata.

## Important
- Do NOT answer from your own pretraining knowledge. If the wiki doesn't know, say so.
- Do NOT modify the wiki as part of answering. `wiki_query` is read-only by design.
